# 공공포털 참고 서울시 조례 Q&A 증강 100문항

작성일 2026-11-12 / portal100-candidate-v2-20261112

공공포털의 시설·민원·정책 안내 주제를 참고해 새로 작성한 합성 문항입니다. 실제 시민 질문 100건을 수집했다는 뜻은 아닙니다. 정답은 기존 실험과 동일한 고정 조례 6개 및 부속 자료에서만 정했습니다. 참고 포털의 최신 요금·운영정보를 정답으로 가져오지 않았습니다.

## 파일

- eval100.json: check.py용 id/type/question/gold/answer_key.
- questions_only100.json: 모델 입력용 ID와 질문만. 정답을 모델에 넣지 않습니다.
- audit100.json: 원문·필수/부가/금지 주장·부재 사유·포털 출처·검토 기록.
- review100.md: 질문·답·근거를 사람이 읽기 위한 목록.
- sources.json: 참고 포털과 문항 연결.
- checks.json / validation.json / revision_log.json / manifest.json: 검증 요약·수정 내역·파일 및 고정 원문 해시.

## 판정 규칙

일반 명제의 참거짓, 규정의 존재·조건을 조례로 판단할 수 있으면 answer입니다. 질문의 핵심이 자료에 없는 금액·절차·개별 사실이면 abstain입니다. abstain의 answer_key는 정확히 '확인 불가', gold는 빈 배열입니다. 부재 사유는 no_related_rule / rule_exists_missing_core_detail로 나눴습니다. 후자는 질문 분야의 직접 관련된 일반 정책·절차 규정이나 위임 규정이 있으나 핵심값이 빠진 경우도 포함합니다. 예를 들어 청년 교육지원의 일반 근거가 있다는 뜻이지 특정 교육사업의 재수강 규정이나 과태료 교육감경제도가 이 조례에서 확인됐다는 뜻은 아닙니다. 이 하위 태그는 check.py 점수에 쓰지 않습니다.

gold의 바깥 배열은 필수 근거 그룹이고 안쪽 배열은 허용 대안입니다. 원본 check.py는 각 그룹에서 가장 잘 맞는 인용에 점수를 부여한 뒤 그룹 평균으로 계산합니다. 만점에는 모든 그룹 충족이 필요합니다. answer_key와 required_claims는 내용 검토용입니다. 기존 check.py가 답변 의미까지 채점한다는 뜻은 아닙니다.

## 검토 상태

100개 모두 별도 AI 에이전트 교차검토를 거쳤고, 이후 다른 3개 AI 에이전트로 전수 재점검했습니다. 6문항을 보완했습니다. 기존 v1과 449개 자료는 보존했습니다. 수정 상세는 revision_log.json 및 second_review.json에 있습니다. 개수·고유 ID·기존449개와 동일 질문 여부·원문 인용 구절·조/항/별표 라벨·check.py 인용 해석·출처 메타데이터를 코드로 점검했습니다. 별표 문항은 원본 HWP의 셀·헤더·비고를 확인했습니다.

사람·법률 전문가 검수 전의 후보 데이터셋이며 공식 대회 정답이 아닙니다. 문장과 의도 중복을 검토했으나 같은 조문·주제의 일부 겹침은 있을 수 있습니다. 모델 성능평가와 유료 API 호출은 하지 않았습니다. 기존 449개, 원본 조례, 기존 점수 및 check.py는 보존하고 이 100개를 별도로 배포합니다.
