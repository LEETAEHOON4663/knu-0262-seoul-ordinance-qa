# HOLD150 — 고정 서울시 조례 6종의 새 질문 평가셋

정리일: 2026-11-17. ZIP 요청사항을 기준으로 작성한 **AI 교차검토 완료 후보**입니다.

## 구성

- 조례 6종 각 25개, 총 150개.
- 단순 조회 30 / 조건 판단 40 / 여러 조항 결합 30 / 근거 없음 50.
- 답변 가능 100개, 확인 불가 50개.
- 확인 불가: 관련 규정 있으나 핵심 세부 없음 20 / 다른 규정·결정에 위임 10 / 개별 운영 사실 10 / 관련 규정 없음 10.
- 별표가 필수인 질문 10개. 표의 행·헤더·단위·주석을 HWP 변환 구조와 대조했습니다.
- 시민 서술형 75 / 직접 질문형 75. 조문 번호가 질문에 들어가는 문항 0개.
- ID 순서는 주차장·동물보호·자전거·도시공원·청년·금연입니다. 모든 산출물의 순서가 같습니다.

## 바로 사용할 파일

| 파일 | 용도 |
|---|---|
| questions150.md | 질문만 읽는 150개 목록 |
| questions_only150.json | 시스템에 넣을 id·question만 포함 |
| eval150.json | 첨부 check.py용 id·type·question·gold·answer_key |
| audit150.json | 주장·원문 인용·기권 사유·기존 질문과의 차이를 포함한 전체 레코드 |
| review150.md | 질문·정답·근거를 함께 읽는 검토본 |
| cross_review150.json | 작성자와 다른 검토자들의 문항별 판정과 수정 기록 |
| validation.json | 개수·인용·원문 일치·중복 점검과 검토 범위 |
| manifest.json | 최종 파일과 입력 자료의 SHA256 |

정답·검토 파일은 답변 모델의 검색 자료나 입력에 넣지 마세요. ID는 결과 대조용이고 답변 모델에는 질문 문장만 전달하세요. 첨부 check.py의 parse/match/score_citation 함수만 사용해 라벨 형식을 확인했으며, QA 실행 함수는 호출하지 않았습니다. gold를 그대로 인용했을 때의 자체 일치 검사는 데이터 형식 검사이며 시스템 점수가 아닙니다.

## 판정 원칙

질문의 일반 명제, 규정의 존재 또는 적용 조건을 고정 자료로 판단할 수 있으면 answer입니다. 핵심 금액·절차·개별 사실이 자료에 없으면 abstain이며 answer_key는 정확히 `확인 불가`, gold는 빈 배열입니다. 위임 주체를 묻는 질문과 위임된 구체 값을 묻는 질문을 구별했습니다.

gold의 바깥 배열은 반드시 필요한 근거 그룹, 안쪽은 동등한 허용 대안입니다. 항이 있는 조문은 항까지 표기하며 호·목은 채점 라벨에 쓰지 않습니다. 필수 주장에는 결론과 결론을 바꾸는 조건을 넣고, 묻지 않은 안내는 필수로 요구하지 않았습니다.

## 제작·점검

기존 초안 150개를 재검토했습니다. 세 작성 에이전트와 다른 세 검토 에이전트가 각각 50개씩 점검했고, 마지막에 형식·수량·근거·파일 일관성을 재확인했습니다. 기존 549개와 문자 유사도 및 같은 근거를 쓰는 문항을 함께 비교했습니다. 같은 사실을 다시 묻는 것으로 판단한 후보는 수정·교체했으며, 같은 조문을 이용하더라도 새로운 핵심 사실이나 조건 적용을 묻는 경우는 허용했습니다. 별표의 기존 요금 사실 재조합을 제외하여 별표 문항은 요청 범위인 10–15개 중 10개로 정리했습니다.

기계 검사에서는 150개 ID·질문 고유성, 모든 gold의 실제 조·항·별표 존재, 원문 인용의 글자 일치, 출처 URL·시행일, 정해진 분포를 확인했습니다. 검토 과정에서 모델이 맞힌 결과나 틀린 결과를 기준으로 문항을 고르지 않았습니다.

## 범위와 한계

**사람·법률 전문가 검수가 아닙니다.** 정확한 인용문 일치가 질문·정답의 모든 의미 해석을 보증하지는 않습니다. 기권 하위 유형의 경계도 AI 판정입니다. 기존 문항과 핵심 사실이 겹칠 가능성을 완전히 배제할 수 없습니다.

별표·법령은 첨부된 버전에 한정했습니다. 현재 웹페이지나 외부 법령으로 정답을 보충하지 않았습니다. 시행일은 평가 실행 날짜가 아니라 각 고정 조례의 메타데이터입니다. HWP 표는 XML 구조로 대조했으며 시각적 렌더링 전체 검수는 수행하지 않았습니다.
