## 찾은 것

1. **작동하지 않는 논리는 하나뿐입니다.** 외부 참조 교정 기권 예외입니다.
   - 조건이 모델의 EXTERNAL 판정에 기대는데, Pro4는 기권할 때 거의 SILENT를 고릅니다(생성 0.5%, 교정 1/54).
   - 수정안(EXTERNAL+SILENT 수용)은 저장 실행 모의(후보 B 실행 제외, 449 21개·증강 14개)에서 이득 7, 손해 0이었습니다. 반영 여부는 HOLD150 모의 결과로 정합니다.
2. **유형(SILENT·DELEGATED·EXTERNAL)을 구분해서 쓰는 곳은 그 예외뿐입니다.**
   - 다른 곳(생성 기권, 유형·상태 충돌, F01)은 "근거 부족 유형이면 무엇이든" 같게 처리합니다.
   - 그래서 Pro4가 EXTERNAL을 거의 안 고르는 것은 이 예외 말고는 결과에 영향이 없습니다.
3. **교정 단계는 주지표에 기여하지 않습니다.**
   - 답을 고친 15건 모두 인용 점수가 그대로였습니다. 문장 내용은 바뀌었을 수 있습니다(E2/E3 대상).
   - 기권 시도는 거부 규칙에 막혀 맞는 기권 절반을 잃습니다. 수정안이 이 부분을 다룹니다.
4. **실패 대비 논리(분해 실패, 임베딩 실패)는 실측에서 발동하지 않았습니다.** 안전장치이므로 유지합니다.
5. **남은 오류의 대부분은 모델 판단 단계에서 나옵니다(PKG11 449).**

## 외부 법령 관련 의사결정 흐름 (단계별 추적)

사용자 요청으로, 외부 법령에 내용을 맡긴 조문이 데이터에서 최종 응답까지 어떻게 다뤄지는지 단계마다 확인했습니다. 숫자는 PKG11 449 실행 기준이고, 괄호는 PKG10입니다.

| 단계 | 외부 참조를 다루는 방식 | 확인한 사실 |
|---|---|---|
| 1. 그래프 추출 | 정규식으로 외부 목록(LIST)·외부 정의(DEFINITION)·외부 법령 위임(EXTERNAL_LAW)을 표시 | 외부 법령을 언급하는 명제 286개 중 표시 34개. 표시 없는 252개는 대부분 "법 제N조에 따라 시장은 …" 같은 근거 인용이라 정상입니다. 그러나 **내용 전체를 외부에 맡긴 조문 3개가 빠졌습니다**: 도시공원 제23조①(과태료 기준 = 영 별표 4), 동물보호 제2조제6호(반려동물 정의 = 시행규칙), 제2조제16호(봉사동물 정의). |
| 2. 질문 분해·검색 | 외부 참조 관련 논리 없음 | — |
| 3. 선택 카드 | 카드 속성에 "위임:EXTERNAL_LAW", "외부 법령 참조: «구간»"을 보여 줌. 지시문은 "조례가 이름만 인용한 외부 법령 목록에 특정 행위가 들어가는지"를 묻는 요청이면 근거를 비우라고 함 | 외부 참조 명제를 고른 함정 24(22)개 중 선택 단계 기권은 3(4)개입니다. 나머지는 선택이 외부 명제를 근거로 넘겼습니다. |
| 4. 전달·렌더 | 외부 참조 표시를 생성·검토 원문에 붙이는 옵션(A-목록 note 등)은 모두 꺼져 있음 | **생성·검토·교정은 외부 참조 표시를 받지 못합니다.** 원문의 "법 제49조 각 호의 행위"를 보고 모델이 스스로 알아차려야 합니다. |
| 5. 생성 | 근거 유형 DIRECT·APPLIED·SILENT·DELEGATED·EXTERNAL 중 선택. EXTERNAL 정의는 "어떤 행위가 그 법의 금지 목록에 드는지"를 명시 | 외부 참조 명제를 받은 함정 21(18)개 중 생성 기권은 18(14)개입니다. 유형은 **SILENT 14, DELEGATED 4, EXTERNAL 0**이고, 나머지 3(4)개는 **DIRECT로 답함**입니다. 449 전체 생성 기권에서도 EXTERNAL은 0건입니다. |
| 5-1. 생성 지시문 안의 충돌 | DIRECT 정의 "가능 여부·의무 여부를 묻는데 원문이 '하여서는 아니 된다' 등으로 정하면 세부가 위임돼 있어도 DIRECT", 마지막 줄 "외부 참조가 있어도 필요한 내용이 원문에 있으면 답한다" | "누구든지 법 제49조 각 호의 행위를 하여서는 아니 된다"는 문장은 금지 규정(DIRECT)으로도, 외부 목록 의존(EXTERNAL)으로도 읽힙니다. 과유보를 줄이려고 넣은 두 문장이 DIRECT 쪽으로 기울게 합니다. 함정에 답한 3(4)개가 모두 이 유형입니다. |
| 6. 상태 처리 | 근거 부족 유형이면 무엇이든 CORE_MISSING → 기권 | 유형 라벨은 결과에 영향이 없습니다. 그래서 생성 단계 기권은 SILENT로 적혀도 정상 작동합니다. |
| 7. 검토 | "원문에 없는 외부 법령 내용을 단정"하면 핵심 미응답 | 생성이 답한 외부 함정 3(4)개 중 1(2)개를 지적했습니다. |
| 8. 교정 | 지적을 받아 유형을 다시 판정 | 지적받은 1(2)개 모두 기권(CORE_MISSING, **SILENT**)으로 바꿨습니다. |
| 9. 교정 기권 수용 | F01(모든 교정 기권 수용)은 꺼짐. 외부 예외는 "유형 EXTERNAL + 검토 지적 + 초안 근거에 그래프 외부 표시" | 유형이 SILENT라 **전부 거부**됐습니다. 이 예외로 받아들인 기권은 저장 실행 전체에서 0건입니다. |
| 10. 인용 조립 | 외부 참조 무관 | — |
| 11. PKG12 A·B(꺼짐) | 답변 후 그래프 표시 기반 점검과 반대 확인 | 켜면 5-1에서 새는 경로를 잡습니다(449 3표본 평균 +0.0045, 손해 1/3). |

- **결론:**
  - Pro4가 EXTERNAL을 거의 안 고르는 것은 생성 단계 기권에는 문제가 없습니다.
  - 그러나 EXTERNAL에 기대는 수용 규칙은 사실상 꺼진 것과 같아서 고쳐야 합니다.
