- **예산:** 사용자 안내에 따라, 실제 청구액은 약 $28이고 추적 한도를 $80으로 올렸습니다. 이 시험의 상한은 $15입니다.

## 수정

| 번호 | 내용 | 적용 방식 |
|---|---|---|
| W1 | 그래프 외부 참조 표시 보완: "외부 법령 … 별표 N과 같다"(외부 법령 위임), "외부 법령 … 에서/로 정하는 X를 말한다"(외부 정의) | 그래프 재빌드. 바뀐 명제는 3개(도시공원 제23조①, 동물보호 제2조제6호·제16호), 다른 명제·간선은 같음. 벡터는 그대로 유효 |
| W2 | 생성 지시문 경계: DIRECT의 "세부가 위임돼 있어도 DIRECT"와 마지막 줄에 "외부 법령 목록·정의에 질문 대상이 드는지가 결론이면 EXTERNAL"을 덧붙임 | 플래그 `pkg_generate_external_rule`(기본 끔). 생성·교정·복구에 같은 지시문 사용 |
| W3 | 외부 참조 표시 전달: 외부 법령에 맡긴 조각에 "외부 법령 … «구간» (맡겨진 내용 자체는 이 자료에 없음)" note를 붙여 생성·검토·교정에 줌 | 플래그 `pkg_render_outside_note`(기본 끔) |

- **문항 문장:** 세 수정 모두 449·증강·HOLD150 문항 문장을 쓰지 않습니다.
- **W1 확인:** W2·W3를 끈 상태의 PKG11 캐시 재생이 PKG11.1과 449/449, 100/100, 150/150 같습니다. 오프라인 검사는 172개가 통과합니다.

## 방법 (입력 고정 비교)

- **고정하는 것:** 질문 분해·근거 선택은 각 세트의 PKG11 trace로 고정하고, 질의 임베딩은 PKG11 캐시를 씁니다.
- **새로 부르는 것:** 생성·검토·교정입니다.
- **대상:** PKG11에서 생성 단계까지 간 문항입니다(449 361개, 증강 100 84개, HOLD150 108개). 선택 단계에서 기권한 문항은 입력이 같아 PKG11 응답을 그대로 씁니다.

## 지표

- **주지표:** check.py 주지표입니다. 문항별로 표본 평균을 낸 뒤 W와 C의 차이를 구합니다(세트 크기로 나눔).
- **구간:** 문항 단위 짝지은 bootstrap 95% 구간(10,000회, seed 20261117)입니다.
- **이득·손해 문항:** W 평균이 C 평균보다 0.5 이상 높으면 이득 문항, 0.5 이상 낮으면 손해 문항입니다.

## 판정 기준 (W 대 C)

| 판정 | 조건 |
|---|---|
| 채택 | 449 구간 하한 > 0, 증강·HOLD150 손해 문항 0, 세 세트 합 손해 문항 1 이하 |

| 판정 보류 | 그 밖 |
